# Pipo store screenshots — real S23 captures

Captured on 2026-11-10 with `adb exec-out screencap -p` on a Samsung Galaxy S23 (SM-S911B, Android 15)
running the installed Pipo 1.0 (versionCode 1). That build is debug-signed but has the same UI as the
public v1.0; the owner approved using these for v1.0 listings. Unedited originals, 1080x2340 PNG,
portrait. No mockups, frames or overlays. The status bar shows ordinary system and app icons only.

The room decorations are Pipo's seasonal **Diwali** decorations (marigold garlands, string lights,
rangoli and diyas), which were live in the app on the capture date.
