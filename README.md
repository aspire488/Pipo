# HE'S NOT WAITING FOR YOU.

### He's got places to be. Things to break. A tiny friend to blame.

</div>

Pipo is an autonomous little robot with a persistent inner life. He makes plans, gets distracted, builds questionable inventions, goes exploring, remembers people, and occasionally just lies on the floor.

You don't manage him. You drop in and discover what happened.

<details>
<summary><strong>THE ENGINE UNDER THE PERSONALITY</strong></summary>

Pipo's life is driven by a deterministic simulation, not a scripted sequence.

- **Personality:** ten traits evolve in bounded steps through experience.
- **Emotion:** continuous internal state drives twelve moods and transient reactions.
- **Autonomy:** activity selection weighs needs, interests, context and unfinished plans.
- **Memory:** persistent events and relationships influence future behaviour.
- **World:** trips, places, weather, neighbours, objects, projects and Nib connect into one simulation.
- **Offline continuity:** elapsed time is reconciled when Pipo returns; no always-running server is required.
- **Local-first:** the core experience persists on-device. Online AI, weather and voice are optional.

</details>

<details>
<summary><strong>RUN IT LOCALLY</strong></summary>

```powershell
git clone https://github.com/aspire488/Pipo.git
cd Pipo
.\gradlew.bat assembleDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`

Install with ADB:

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Android 8.0 (API 26) or newer.

</details>
